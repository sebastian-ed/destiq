# DestsIQ

**DestIQ** es una herramienta que permite transformar datos turísticos dispersos —planillas, series mensuales, indicadores oficiales o registros propios— en tableros visuales, comparaciones y reportes exportables para gestión, planificación y toma de decisiones.


## Funcionalidades principales

### Gestión por destino

Cada destino puede tener sus propios indicadores, agrupados visualmente por tema o categoría.

Ejemplos de grupos:

* Establecimientos
* Viajeros
* Ocupación hotelera
* Estadía promedio
* Plazas disponibles
* Habitaciones ocupadas
