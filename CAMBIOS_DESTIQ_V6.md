# DestIQ v6 — Monitor completo

## Criterio
- Partimos de DestIQ(6).rar y preservamos módulos y visualizaciones originales.
- Se mantienen CSS original, colores y configuraciones Chart.js. Solo se añade estilo de navegación.
- Orden de lectura: resumen de destino y detalle, luego comparación de destinos, rankings y hallazgos.
- Navegación persistente de siete secciones, sin ocultar módulos.
- Panel de administración disponible como `/admin.html` y `/pages/admin.html`.

## Nota
La navegación de resumen/períodos/evolución/datos requiere que se seleccione primero un destino/indicador. Las comparaciones territoriales, rankings y hallazgos se pueden abrir directamente. No se modificó el esquema de Supabase.
